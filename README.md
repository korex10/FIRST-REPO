


# First Repo

1. For the first commit/creation of a new repository, you must initialize the repo.
2. Stage any changes made, using the `+` in source control next to changes section.
3. Commit staged files, with a descript message. This permenantly saves

- Staging files - youve made changes and you want to POSSIBLY save them permenantly as a version.
- Commit files - you give a message to the version you are permenantly saving.
    - make sure the message is descriptive.
